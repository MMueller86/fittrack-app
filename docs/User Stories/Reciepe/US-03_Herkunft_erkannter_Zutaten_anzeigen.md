# User Story – Herkunft erkannter Zutaten anzeigen

## User Story

Als Nutzer möchte ich nachvollziehen können, aus welchen Textstellen meines Rezeptes erkannte Zutaten stammen, damit ich die Erkennung besser verstehen und mögliche Fehler schneller korrigieren kann.

## Akzeptanzkriterien

1. Für jede erkannte Zutat kann die zugrunde liegende Textstelle angezeigt werden.
2. Die Herkunft einer Zutat ist direkt über die Benutzeroberfläche erreichbar.
3. Die ursprüngliche Textstelle wird vollständig und nachvollziehbar dargestellt.

## Hinweise für den Planner

- Die Herkunft einer Zutat soll über eine für Mobile geeignete Interaktion erreichbar sein.
- Die Herkunft einer Zutat soll möglichst präzise im ursprünglichen Rezepttext hervorgehoben werden können.
