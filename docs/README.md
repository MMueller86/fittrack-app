# docs/

Product specifications and planning documents for FitTrack.

These are the authoritative source of truth for the MVP.

## Files

| File | Purpose |
|---|---|
| `master_prompt.md` | Planning master prompt and task list |
| `product_requirements.md` | MVP product requirements |
| `epics_and_stories.md` | Epics and user stories |
| `calculation_logic.md` | Mifflin-St Jeor formula and nutrition target logic |
| `architecture.md` | Architecture overview |
| `data_model.md` | Cosmos DB containers and data model |
| `api_design.md` | API design principles and domain grouping |
| `screen_flows.md` | Screen flow and navigation spec |
| `non_functional_requirements.md` | Non-functional requirements |
| `azure_environment.md` | Azure environment setup and naming |
| `design_assets_notes.md` | Notes on visual design assets |

## Rules

- Written specs take precedence over visual assets
- Do not add new features not described in these files
- If a visual asset conflicts with written specs, follow the written specs
